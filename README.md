# 🤖 Nova Rule-Based AI Chatbot

## 📌 Description
Nova is a simple rule-based AI chatbot built using Python. It uses predefined rules and user inputs to provide responses.

The chatbot can:
* Respond to greetings
* Answer basic questions
* Tell the current time
* Tell today's date
* Show conversation count
* Display available commands
* Handle unknown inputs

## 🛠️ Technologies Used
* Python
* datetime module

## ▶️ How to Run
1. Make sure Python is installed
2. Open project folder in VS Code
3. Run this command:
python chatbot.py
4. Start chatting with Nova. Type `help` to see commands.

## 💬 Example Commands
hello
how are you
what is your name
who created you
what can you do
what time is it
what is today's date
conversation count
help
bye
